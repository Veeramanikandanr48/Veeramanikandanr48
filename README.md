## About Me

I am a **Full Stack Developer** and **Data Analyst** from Tamil Nadu, India. I build end-to-end products with **React, Next.js, Node.js, NestJS, TypeScript, PostgreSQL and MongoDB**, and I enjoy turning complex data into clear, useful decisions.

- Building production systems for **invoicing, payroll, attendance, reporting and ESG/carbon accounting**.
- Contributing to **open source** across Storybook, DeskcommCRM, openslop and developer tooling.
- Exploring **AI agents, RAG, applied machine learning and data visualisation**.
- Open to **full-stack engineering, data analyst and open-source collaboration** opportunities.

> I care about clean architecture, useful tests, accessible UI and code that is easy for the next person to change.
